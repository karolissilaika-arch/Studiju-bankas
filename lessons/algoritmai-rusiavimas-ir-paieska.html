Burbulinis rūšiavimas

PYTHON
def burbulinis(a): n = len(a) for i in range(n-1): for j in range(n-i-1): if a[j] > a[j+1]: a[j], a[j+1] = a[j+1], a[j] return a print(burbulinis([5,3,8,1])) # [1, 3, 5, 8]
C++
void burbulinis(int a[], int n) { for(int i=0;i<n-1;i++) for(int j=0;j<n-i-1;j++) if(a[j]>a[j+1]) { int t=a[j]; a[j]=a[j+1]; a[j+1]=t; } }

Dvejetainė paieška

Dvejetainė paieška veikia tik surūšiuotame masyve. Kiekvienu žingsniu padalina paiešką per pusę – O(log n).

PYTHON
def dvejetaine(a, x): k, d = 0, len(a) - 1 while k <= d: vid = (k + d) // 2 if a[vid] == x: return vid elif a[vid] < x: k = vid + 1 else: d = vid - 1 return -1 # nerastas
C++
int dvejetaine(int a[], int n, int x) { int k=0, d=n-1; while(k <= d) { int v=(k+d)/2; if(a[v]==x) return v; else if(a[v]<x) k=v+1; else d=v-1; } return -1; }
⌨ Praktinė užduotis
Parašyk programą kuri nuskaito N skaičių iš failo, surūšiuoja juos ir tada n kartų ieško konkretaus skaičiaus naudojant dvejetainę paiešką. Kiekvienam ieškojimui išveda ar rastas ir kokioje pozicijoje.
⚠ Svarbu VBE: VBE egzaminuotojai dažnai nori matyti rankinį rūšiavimą (ne sort()), kad matytų algoritmų supratimą. Dvejetainė paieška – tik surūšiuotam masyvui. Tiesinė paieška – O(n), veikia bet kur.
