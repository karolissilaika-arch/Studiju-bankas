Funkcijos ir procedūros

Funkcijos leidžia kodą skaidyti į dalis, išvengti kartojimosi ir kurti aiškesnę struktūrą. VBE užduotyse dažnai reikia parašyti kelias tarpusavyje sąveikaujančias funkcijas.

Funkcijos apibrėžimas ir kvietimas

PYTHON
def kvadratas(x): return x * x def pasisveikinti(vardas): print(f"Labas, {vardas}!") # Kvietimas rez = kvadratas(5) print(rez) # 25 pasisveikinti("Tomas")
C++
int kvadratas(int x) { return x * x; } void pasisveikinti(string v) { cout << "Labas, " << v; } int main() { int rez = kvadratas(5); cout << rez; // 25 pasisveikinti("Tomas"); }

Rekursija

Rekursija – kai funkcija kviečia pati save. Būtina turėti bazinį atvejį (išeities sąlygą), kitaip programa užstrigs.

PYTHON – faktorialas
def faktorialas(n): if n == 0: # bazinis atvejis return 1 return n * faktorialas(n-1) print(faktorialas(5)) # 120
C++ – Fibonačis
int fib(int n) { if (n <= 1) return n; return fib(n-1) + fib(n-2); } // fib(0)=0, fib(1)=1 // fib(6)=8

⌨ Praktinė užduotis
Parašyk funkciją didžiausias(a, b, c), kuri grąžina didžiausią iš trijų skaičių. Tada parašyk funkciją ar_pirminis(n), kuri patikrina ar skaičius yra pirminis.

Tikėtinas rezultatas: didžiausias(3,7,2) → 7  |  ar_pirminis(17) → True
⚠ Svarbu VBE: Rekursijoje visada rašyti bazinį atvejį pirma. C++ void funkcija nieko negrąžina. Python funkcija be return grąžina None.
