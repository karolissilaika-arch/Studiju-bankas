Trigonometrinės funkcijos ir tapatybės

Pagrindinės tapatybės

Pagrindinė tapatybė\[ \sin^2 x + \cos^2 x = 1 \]
Iš jos išvedamos\[ \tan^2 x + 1 = \dfrac{1}{\cos^2 x} \]
Dvigubo kampo\[ \sin 2x = 2\sin x\cos x \]
Dvigubo kampo\[ \cos 2x = \cos^2 x - \sin^2 x \]
Sumos formulė\[ \sin(A\pm B) = \sin A\cos B \pm \cos A\sin B \]
Sumos formulė\[ \cos(A\pm B) = \cos A\cos B \mp \sin A\sin B \]

Sinuso ir cosinuso funkcijų grafikai \([-2\pi, 2\pi]\)

Trigonometrinės lygtys

\(\sin x = a\)\[ x = (-1)^n \arcsin a + \pi n,\; n \in \mathbb{Z} \]
\(\cos x = a\)\[ x = \pm\arccos a + 2\pi n,\; n \in \mathbb{Z} \]
\(\tan x = a\)\[ x = \arctan a + \pi n,\; n \in \mathbb{Z} \]
Pavyzdys

Išspręsti: \(2\sin^2 x - \sin x - 1 = 0\)

  1. Pažymime \(t = \sin x\): \(2t^2 - t - 1 = 0\)
  2. Diskriminantas: \(D = 1 + 8 = 9\), šaknys: \(t_1 = 1\), \(t_2 = -\tfrac{1}{2}\)
  3. Jei \(\sin x = 1\): \(x = \tfrac{\pi}{2} + 2\pi n\)
  4. Jei \(\sin x = -\tfrac{1}{2}\): \(x = -\tfrac{\pi}{6} + 2\pi n\) arba \(x = \pi + \tfrac{\pi}{6} + 2\pi n = \tfrac{7\pi}{6} + 2\pi n\)
