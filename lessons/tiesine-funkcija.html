Tiesinė funkcija

Pagrindinė forma

Tiesinė funkcija \[f(x) = kx + b\]

\(k\) — krypties koeficientas (liestinė), \(b\) — ordinatės atkarpėlė

Tiesės lygtis koordinačių sistemoje

Per du taškus\[k = \dfrac{y_2 - y_1}{x_2 - x_1}\]
Lygiagrečios tiesės\[k_1 = k_2\]
Statmenos tiesės\[k_1 \cdot k_2 = -1\]
Tiesės lygtis per tašką\[y - y_0 = k(x - x_0)\]

Tiesės grafikas

Tiesių susikirtimo taškas

Pavyzdys

Raskite tiesių \(y = 2x + 1\) ir \(y = -x + 4\) susikirtimo tašką.

Lyginame: \(2x + 1 = -x + 4 \Rightarrow 3x = 3 \Rightarrow x = 1\)

\(y = 2(1) + 1 = 3\). Taškas: \((1;\, 3)\)

⚠ Svarbu: Jei \(k > 0\) — tiesė kyla, jei \(k < 0\) — leidžiasi, jei \(k = 0\) — horizontali.
