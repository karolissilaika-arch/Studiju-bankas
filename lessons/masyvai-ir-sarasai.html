Masyvai ir sąrašai

Masyvai ir sąrašai – pagrindinės duomenų struktūros VBE užduotyse. Beveik kiekvienoje programavimo užduotyje reikia skaityti, apdoroti ir rūšiuoti duomenų rinkinius.

Sąrašo kūrimas ir prieiga

PYTHON
# Kūrimas a = [5, 3, 8, 1, 9] # Prieiga pagal indeksą (nuo 0) print(a[0]) # 5 print(a[-1]) # 9 (paskutinis) # Ilgis print(len(a)) # 5 # Pridėti / pašalinti a.append(4) a.remove(3)
C++
#include <iostream> using namespace std; int main() { int a[] = {5,3,8,1,9}; int n = 5; // dydis cout << a[0]; // 5 cout << a[n-1]; // 9 // Iteravimas for(int i=0; i<n; i++) cout << a[i] << " "; }

Skaitymas iš failo į masyvą

PYTHON
with open("duom.txt") as f: n = int(f.readline()) a = [] for _ in range(n): a.append(int(f.readline()))
C++
#include <fstream> ifstream fin("duom.txt"); int n; fin >> n; int a[1000]; for(int i=0;i<n;i++) fin >> a[i]; fin.close();

Rūšiavimas

PYTHON
a = [5, 2, 8, 1] # Didėjančiai a.sort() # arba: sorted(a) # Mažėjančiai a.sort(reverse=True) # Pagal raktą a.sort(key=lambda x: -x)
C++
#include <algorithm> // Didėjančiai sort(a, a+n); // Mažėjančiai sort(a, a+n, greater<int>()); // Burbulinis (VBE stilius) for(int i=0;i<n-1;i++) for(int j=0;j<n-i-1;j++) if(a[j]>a[j+1]) swap(a[j],a[j+1]);

⌨ Praktinė užduotis
Failas duom.txt pirmoje eilutėje turi skaičių N, toliau N skaičių. Nuskaityti, surūšiuoti ir į failą rez.txt išvesti:
1) Surūšiuotą sąrašą
2) Vidurkį (2 skaitmenų po kablelio tikslumu)
3) Kiek skaičių yra didesnių už vidurkį
⚠ Svarbu VBE: C++ masyvo dydis turi būti žinomas kompiliavimo metu – apibrėžti su pakankamu dydžiu (pvz. int a[10000]). Python sąrašas dinamiškas. VBE dažnai reikia rūšiuoti ir skaičiuoti statistikas.
