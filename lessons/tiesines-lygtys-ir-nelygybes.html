Tiesinės lygtys ir nelygybės

Tiesinė lygtis

Bendroji forma \[ax + b = 0 \quad \Rightarrow \quad x = -\frac{b}{a} \quad (a \ne 0)\]
Pavyzdys

Išspręsti: \(3x - 7 = 2x + 5\)

  1. Perkeliame \(x\) į kairę: \(3x - 2x = 5 + 7\)
  2. Supaprastiname: \(x = 12\)

Tiesinė nelygybė

Taisyklė\[ax < b \Rightarrow x < \frac{b}{a} \text{ (jei } a>0)\]
Svarbu!\[ax < b \Rightarrow x > \frac{b}{a} \text{ (jei } a<0)\]

Absoliučioji reikšmė (modulis)

Apibrėžimas\[|a| = \begin{cases} a, & a \ge 0 \\ -a, & a < 0 \end{cases}\]
Lygtis\[|x| = a \Rightarrow x = a \text{ arba } x = -a\]
Nelygybė\[|x| < a \Rightarrow -a < x < a\]
Nelygybė (>)\[|x| > a \Rightarrow x < -a \text{ arba } x > a\]
Pavyzdys su moduliu

Išspręsti: \(|2x - 3| \le 5\)

  1. Užrašome: \(-5 \le 2x-3 \le 5\)
  2. Sudedam 3: \(-2 \le 2x \le 8\)
  3. Daliname iš 2: \(-1 \le x \le 4\)
  4. Atsakymas: \(x \in [-1;\, 4]\)
⚠ Svarbu: Daugindami ar dalindami nelygybę iš neigiamo skaičiaus, būtinai apverčiame nelygybės ženklą!
