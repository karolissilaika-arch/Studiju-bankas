Duomenų tyryba – analizė Python

VBE duomenų tyrybos užduotis galima atlikti Python su standartiniu csv moduliu – be papildomų bibliotekų. Svarbu mokėti skaičiuoti statistikas ir filtruoti duomenis.

Statistinių rodiklių skaičiavimas

import math def statistika(duomenys): n = len(duomenys) if n == 0: return vidurkis = sum(duomenys) / n # Mediana surusiuoti = sorted(duomenys) if n % 2 == 0: mediana = (surusiuoti[n//2-1] + surusiuoti[n//2]) / 2 else: mediana = surusiuoti[n//2] # Standartinis nukrypimas dispersija = sum((x - vidurkis)**2 for x in duomenys) / n std = math.sqrt(dispersija) print(f"Vidurkis: {vidurkis:.2f}") print(f"Mediana: {mediana:.2f}") print(f"Standartinis nukrypimas: {std:.2f}") print(f"Min: {min(duomenys)}, Max: {max(duomenys)}")

CSV skaitymas ir filtravimas

import csv def analizuoti(failas): mokiniai = [] with open(failas, encoding="utf-8") as f: sk = csv.DictReader(f, delimiter=";") for eil in sk: mokiniai.append({ "vardas": eil["Vardas"], "klase": eil["Klasė"], "balas": int(eil["Balas"]) }) # Filtruoti pagal balą auksti = [m for m in mokiniai if m["balas"] >= 80] # Grupuoti pagal klasę klases = {} for m in mokiniai: k = m["klase"] if k not in klases: klases[k] = [] klases[k].append(m["balas"]) # Vidurkis kiekvienai klasei for k, balai in klases.items(): vid = sum(balai) / len(balai) print(f"{k}: vidurkis = {vid:.2f}")

⌨ Praktinė užduotis
CSV failas turi stulpelius: Miestas;Metai;Temperatūra. Parašyk programą kuri:
1) Randa karštiausią ir šalčiausią mėnesį kiekvienam miestui
2) Apskaičiuoja metinį temperatūros vidurkį
3) Suranda metus kai temperatūra labiausiai nukrypo nuo vidurkio
4) Rezultatus išrašo į naują CSV failą
⚠ Svarbu VBE: csv.DictReader automatiškai naudoja pirmą eilutę kaip stulpelių pavadinimus – labai patogu. Visada patikrinti ar duomenys teisingi prieš skaičiuojant (pvz. ar nėra tuščių reikšmių).
