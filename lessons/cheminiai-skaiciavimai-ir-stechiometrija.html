🧮 Cheminiai skaičiavimai ir stechiometrija

Stechiometrija – kiekybinių santykių chemijoje mokslas. 25% VBE taškų skiriama skaičiavimo uždaviniams. Šios temos mokėjimas tiesiogiai lemia galutinį balą.

Pagrindinės formulės

Medžiagos kiekis
n = m / M
Molinė masė
M = Σ Aᵣ
Dalelių skaičius
N = n · Nₐ
Dujų tūris (STP)
V = n · 22,4 L
Molinė koncentracija
c = n / V(L)
Masės dalis
ω = m(tirp.) / m(tirp.)
Nₐ = 6,022 × 10²³ mol⁻¹ (Avogadro konstanta)
STP: T = 273 K, P = 101,3 kPa (1 atm), Vm = 22,4 L/mol
Idealiųjų dujų lygtis: PV = nRT, R = 8,314 J/(mol·K)

Stechiometrinio skaičiavimo žingsniai

  1. Parašyk ir subalansuok reakcijos lygtį
  2. Surašyk duotus dydžius ir ko ieškoma
  3. Pavers visus dydžius į molius (n = m/M arba n = V/22,4)
  4. Naudok stechiometrinius koeficientus proporcijoms
  5. Pavers molius į prašomą dydį (masę, tūrį, koncentraciją)

Tirpalų skaičiavimai

c (mol/L) = n / V
Praskiedimas: c₁V₁ = c₂V₂
Tirpalo masė: m(tirp.) = ρ · V
Masės dalis → molinė c: c = (ω · ρ · 1000) / M

Reakcijos išeiga

Teorinė masė: pagal stechiometriją
Praktinė masė: eksperimento rezultatas
Išeiga (%) = (m(praktinė) / m(teorinė)) × 100%
📝 Praktinė užduotis
25 g kalcio karbonato CaCO₃ (M = 100 g/mol) reaguoja su druskos rūgštimi: CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂. (a) Kiek molių CO₂ išsiskiria? (b) Koks CO₂ tūris (STP)? (c) Kiek litrų 2 mol/L HCl reikia?
⚠ Svarbu VBE: Stechiometrijos uždaviniai – kiekvienais metais egzamine. Dažnai jungiama su tirpalų koncentracija arba dujų tūriais. Nepamirštama: STP sąlygos (0°C, 1 atm) ir Avogadro skaičius. Visada tikrink vienetų suderinamumą.
