Duomenų struktūros – žodynai ir aibės

Žodynai (dict/map) ir aibės (set) leidžia efektyviai saugoti ir ieškoti duomenų. Ypač naudingi kai reikia skaičiuoti pasikartojimus arba rasti unikalius elementus.

Žodynas (Python dict / C++ map)

PYTHON
# Kūrimas balai = {"Jonas": 85, "Ona": 92} # Prieiga print(balai["Jonas"]) # 85 # Pridėti / keisti balai["Tomas"] = 78 # Tikrinti ar raktas yra if "Ona" in balai: print(balai["Ona"]) # Iteruoti for vardas, balas in balai.items(): print(vardas, balas) # Skaičiuoti pasikartojimus kiek = {} for z in zodziai: kiek[z] = kiek.get(z, 0) + 1
C++
#include <map> using namespace std; map<string, int> balai; // Pridėti balai["Jonas"] = 85; balai["Ona"] = 92; // Tikrinti if(balai.count("Ona")) cout << balai["Ona"]; // Iteruoti for(auto p : balai) cout << p.first << " " << p.second; // Skaičiuoti map<string,int> kiek; kiek[zodis]++;

Aibė (Python set / C++ set)

PYTHON
a = {1, 2, 3, 2, 1} print(a) # {1, 2, 3} # Unikalūs elementai iš sąrašo unikalus = set([1,2,2,3]) # Pridėti a.add(4) # Ar yra if 2 in a: ... # Sankirta, sąjunga b = {2, 3, 5} print(a & b) # {2, 3} print(a | b) # {1,2,3,4,5}
C++
#include <set> set<int> a; a.insert(1); a.insert(2); a.insert(2); // dublikatas ignoruojamas // Ar yra if(a.count(2)) ... // Dydis a.size(); // Iteruoti (surūšiuota tvarka) for(int x : a) cout << x << " ";
⌨ Praktinė užduotis
Failas turi mokinių vardus (po vieną eilutėje, kai kurie kartojasi). Parašyk programą kuri:
1) Randa kiek unikalių mokinių
2) Randa dažniausiai pasikartojantį vardą ir kiek kartų jis kartojasi
3) Išveda vardus abėcėlės tvarka be pasikartojimų
⚠ Svarbu VBE: Python dict.get(raktas, numatytoji) – patogus būdas išvengti KeyError. C++ map automatiškai inicializuoja trūkstamus raktus su 0 (int atveju). Aibės elementai C++ išvedami surūšiuota tvarka.
