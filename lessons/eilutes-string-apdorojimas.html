C++ string operacijos

#include <string> #include <algorithm> using namespace std; string s = "Labas pasauli"; // Ilgis s.length(); // arba s.size() // Pjūvis s.substr(0, 5); // "Labas" // Paieška s.find("pas"); // grąžina poziciją arba string::npos // Keitimas s.replace(6, 7, "drauge"); // nuo poz.6, 7 simboliai // Didžiosios raidės transform(s.begin(), s.end(), s.begin(), ::toupper);

Pavyzdys: žodžių skaičiavimas

PYTHON
teksts = "labas rytas geras" zodziai = teksts.split() print(len(zodziai)) # 3 # Unikalūs žodžiai unikalus = set(zodziai) print(len(unikalus))
C++
#include <sstream> string teksts = "labas rytas"; istringstream iss(teksts); string zodis; int kiek = 0; while(iss >> zodis) kiek++; cout << kiek; // 2
⌨ Praktinė užduotis
Failas turi teksto eilutes. Parašyk programą kuri:
1) Suskaičiuoja kiek žodžių prasideda didžiąja raide
2) Randa dažniausiai pasikartojantį žodį
3) Išveda tekstą atvirkštine žodžių tvarka
⚠ Svarbu VBE: Python split() be argumento dalina pagal bet kokį tarpą (taip pat tabuliavimą). C++ string::npos reiškia "nerastas". Lyginant eilutes Python – tiesiog ==, C++ – taip pat == su string tipo kintamaisiais.
