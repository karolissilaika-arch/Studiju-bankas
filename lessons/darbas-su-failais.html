Darbas su failais

VBE II dalyje programos visada skaito duomenis iš failo ir rašo rezultatus į failą. Tai vienas iš privalomų gebėjimų.

Tipinis VBE failo formatas

Įvesties failas duom.txt:

5
12 7 34 5 19

Arba kiekvienas skaičius atskiroje eilutėje:

5
12
7
34
5
19

Skaitymas ir rašymas

PYTHON – pilnas šablonas
# Skaitymas with open("duom.txt", "r") as f: n = int(f.readline()) # Viena eilutė su skaičiais: a = list(map(int, f.readline().split())) # Arba po vieną eilutėje: # a=[int(f.readline()) for _ in range(n)] # Rašymas with open("rez.txt", "w") as f: f.write(f"{rezultatas}\n") # Sąrašas į vieną eilutę: f.write(" ".join(map(str, a)) + "\n")
C++ – pilnas šablonas
#include <iostream> #include <fstream> using namespace std; int main() { ifstream fin("duom.txt"); ofstream fout("rez.txt"); int n; fin >> n; int a[10000]; for(int i=0;i<n;i++) fin >> a[i]; // apdorojimas... fout << rezultatas << endl; fin.close(); fout.close(); return 0; }

Teksto eilučių apdorojimas (Python)

with open("duom.txt", "r", encoding="utf-8") as f: eilutes = f.readlines() for eil in eilutes: eil = eil.strip() # pašalinti tarpus ir \n dalis = eil.split(";") # padalinti pagal ";" vardas = dalis[0] amzius = int(dalis[1])
⌨ Praktinė užduotis
Failas mokiniai.txt kiekvienoje eilutėje turi: Vardas;Pavardė;Balas
Parašyk programą, kuri:
1) Nuskaito visus mokinius
2) Randa aukščiausią balą
3) Į rez.txt išveda geriausio mokinio vardą ir balą
⚠ Svarbu VBE: Python naudoti encoding="utf-8" jei failas turi lietuviškų raidžių. C++ ifstream/ofstream privalo būti uždaryti arba naudoti su scope. Visada tikrinti ar failas atidarytas sėkmingai.
